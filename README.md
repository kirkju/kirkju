## Now

- Programmer at Avance Enterprise Solutions (AVNC), on the team building a full-stack CRM platform in Rust (Actix-web) and PostgreSQL with an HTML-first UI (HTMX).
- Building an AI-assisted multichannel campaign system with FastAPI, PostgreSQL, and React, where an LLM drafts the messages and a person confirms every send.
- Piloting an offline-first Flutter app that collects farm data in the field for EU Deforestation Regulation (EUDR) compliance.
